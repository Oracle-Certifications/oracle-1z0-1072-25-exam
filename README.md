## 5. Scenario-Based Demo & Practice Questions

### Question 1
An architect needs to secure network traffic to a database compute instance in a private subnet. Which OCI networking feature allows applying security rules directly to a specific instance's virtual network interface (VNIC) rather than the entire subnet?

A) Security List
B) Network Security Group (NSG)
C) Internet Gateway
D) Route Table

- **Correct Answer**: `B) Network Security Group (NSG)`
- **Technical Explanation**: Network Security Groups (NSGs) allow security rules to be applied directly to a set of VNICs within a VCN, offering finer-grained security control compared to subnet-level Security Lists.

---

### Question 2
Which OCI storage service provides a POSIX-compliant distributed filesystem that can be concurrently mounted by thousands of compute instances over NFSv3?

A) Object Storage
B) Block Volume
C) File Storage Service (FSS)
D) Archive Storage

- **Correct Answer**: `C) File Storage Service (FSS)`
- **Technical Explanation**: OCI File Storage Service (FSS) is a fully managed, elastic, shared file system that supports enterprise POSIX standards and NFSv3 protocol for high-concurrency access.
